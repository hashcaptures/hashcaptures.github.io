# hashcaptures.github.io

Personal GitHub Pages site for `hashcaptures`.

## About

This repository contains the source files published through GitHub Pages. Open the site at [hashcaptures.github.io](https://hashcaptures.github.io).

## Development

Because this is a static site, you can preview it locally by serving the repository directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publishing

Push changes to the repository's default branch. GitHub Pages will publish the site based on the repository settings.
